## 👋 About Us

Lpay(Lions Pay)는 **멋쟁이사자처럼 대학 을지대학교**에서 만든 QR 코드 기반 테이블 주문·결제 서비스입니다.
손님은 테이블의 QR 코드를 찍어 모바일로 메뉴를 주문하고 바로 결제하며, 주점 운영자는 아이패드 POS에서 들어온 주문을 실시간으로 관리합니다.

2026년 7월 개발을 시작해, **2026.09.30–10.01 을지대학교 축제**에서 두 개 주점(어흥주막, 영양학개론:주류편)에 시범 도입했습니다.
기획부터 디자인, 개발, QA, 브랜딩, 홍보까지 모든 과정을 학생들이 직접 맡아 실제 사용자와 실제 결제를 다루는 서비스를 만들고 운영합니다.

## ✨ Key Features

- **QR 테이블 주문**: 앱 설치 없이 QR 코드만 찍으면 바로 주문
- **간편결제 지원**: 토스, 카카오페이, 네이버페이, 카드결제
- **주문 내역 확인**: 손님이 자신의 주문 상태를 직접 확인
- **POS 주문 관리**: 운영자가 아이패드(POS기)에서 주문을 접수하고 관리
